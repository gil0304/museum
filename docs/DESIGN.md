# デザイン：画面レイアウトと共通スタイル

確定: 2026-11-20（TMS 32）。値の正本は `src/styles/tokens.css`（色・文字・余白・角丸・影・重なり順）、部品は `src/styles/components.css`（クラス名は `m-` で始める）。
見本ページ: `npm run dev` → http://localhost:5173/spikes/style-guide.html （色・文字・ボタン・パネル・画面レイアウト4種のモック）

## トーン
- **主役は作品と展示室**。UI は暗いチャコールの「額縁」として外側に置き、展示室（明るい壁・床）を邪魔しない。
- 見出し・作品名・ロゴは**明朝／セリフ体**（美術館の図録の雰囲気）、操作UIは**ゴシック**、小見出しラベル（`EXHIBIT / 001`）と座標は**等幅**。
- アクセントは**真鍮色**（`--c-accent` #c9a86a）。ロゴ周り、選択中のツール、配置プレビュー、暗い面の小見出しに使う。赤（`--c-danger`）は削除など取り消しにくい操作だけ。
- Webフォントは読み込まない（静的配信・軽さ・オフライン優先）。端末の明朝・ゴシックを使う。

## 画面レイアウト（提出版）
画面はタイトル画面と3Dビュー（鑑賞・編集）の2つ（[SUBMISSION_EXPERIENCE.md](SUBMISSION_EXPERIENCE.md)）。モックは見本ページの「LAYOUT」。

### 画面の切り替え（URL のハッシュ、TMS 33 で実装）
| URL | 画面 |
|---|---|
| `/`（ハッシュなし） | タイトル画面（背景はサンプル美術館） |
| `#/view/sample` | サンプル美術館を鑑賞 |
| `#/view/empty` | 空の部屋（床と四方の壁）。編集モード（TMS 39〜）ができるまでは鑑賞で表示 |
| `#/view/continue` | 前回の編集（ブラウザ内の保存 `museum.autosave.v1`。保存処理は TMS 57）。無い・壊れているときはサンプル |

- 公開先の書き換え（rewrite）に頼らないため、パスではなくハッシュを使う。ブラウザの「戻る」でタイトルに戻れ、URL を共有すれば直接その画面を開ける（TMS 59 の共有URLの土台）。
- フォーカス: 画面を切り替えたとき（タイトル→鑑賞はロゴ、鑑賞→タイトルは主ボタン）だけ移す。URL を直接開いた最初の表示では動かさない。

### ① タイトル画面（TMS 33）
- 背景は**実際のサンプル展示室の3D**（ゆっくり動かしてもよい）。左側を展示室の色のグラデーションで覆い、文字を読みやすくする。
- 左に小見出し `MUSEUM`、見出し「自分の世界を、美術館にする。」、主ボタン「サンプル美術館に入る」（`m-btn--primary m-btn--lg`）、副ボタン「空の部屋から作る」（`--secondary`）、前回の編集があるときだけ「続きから」（`--ghost`）。

### ② PC・鑑賞モード
- **3D は画面全体**（現在のプロトタイプの上下の帯はやめる）。
- 上部バー: 左にロゴ（クリックでタイトルへ）、中央に「鑑賞 / 編集」切替、右に「ヘルプ」「メニュー」（JSON書き出し・読み込み、サンプルに戻す、画質）。
- 右下に作品情報パネル（作品をクリックで表示、Esc・閉じるで隠す）。左下に操作ヒント（ドラッグ：見回す、WASD / 矢印：歩く、Shift：速く、Q / E：向きを変える）。
- 視点（TMS 36）: 目の高さ 1.6m、部屋の手前の壁から 1.2m 内側に立って奥を向いて始まる。ドラッグで見回す（右へドラッグで右を向く、1px ≈ 0.24°）。上下は約 ±63° まで。Q / E を押し続けると左右に向きを変える（約 92°/秒）。文字入力中はキーを受け取らない。指のドラッグも同じ。
- 部屋は四方を壁で閉じる（後ろを振り向いても部屋の外が見えないように）。
- 移動（TMS 37）: WASD・矢印キーで、向いている方向を基準に床と平行に歩く（矢印の左右は横歩き。向きを変えるのは Q / E とドラッグ）。歩く速さ 1.8m/秒、Shift で 3.4m/秒。斜めでも速くならない。歩き出し・止まりは少し滑らか（動きを減らす設定では即座）。別のウィンドウへ移ったらキーを離したことにする。壁の通り抜け防止は TMS 38。
- HTML作品には `m-badge`「◆ 操作できるHTML作品」を作品情報に出す。

### ③ PC・編集モード
- 視点は斜め上から。床にグリッドと配置プレビュー（真鍮色の半透明）。
- 左にツールパレット（選択・床・壁・作品・削除）、右上に選択中のパーツ・作品の情報（暗いインスペクタ、幅 300px）。
- 左下のヒントは `m-hint--with-palette` でパレットの右に置き、グリッド座標と主な操作キーを出す。
- 上部バー右は保存状態（「保存済み」）とメニュー。

### ④ スマホ（幅 700px 以下）・鑑賞のみ
- 上部バーを 48px に縮め、編集の切替は出さない（「編集はPCで」と案内）。
- 作品情報は画面下からのシート。
- 操作（TMS 36〜37 で決定）: 指のドラッグで見回し、**右下の移動ボタン**（前・後ろ・左・右、各 52px）を押している間歩く。指 2 本で 2 方向同時も可。押している間ボタンは真鍮色。移動ボタンはタッチ端末（`pointer: coarse`）か幅 700px 以下で表示し、左下のヒントと重ならない高さに置く。

## 展示室の照明と影（TMS 35）
照明は固定（ユーザーは置けない）。値の正本は `src/scene/room.ts` の `LIGHT`、描画設定は `src/scene/viewer.ts`。
| 光 | 役割 | 影 |
|---|---|---|
| 半球光（上 #fffaf2 / 下 #b3a797、1.5） | 部屋全体の明るさ。下の色を暗くすると横の壁が沈むので明るめにする | なし |
| 主光（平行光 #fff1de、1.7、部屋の中心から (-1.2, 7, 4.5)） | 天井の照明から降りる光。壁に約57°で当て、額縁の影が下に短く（約0.2m）落ちる | あり |
| 補助光（平行光 #f3f1ff、0.55、手前右） | 壁と作品の正面を起こす | なし |
| 天井 | 光る帯は見た目だけ。天井の面は少し自ら光らせて暗く沈まないようにする | 落とさない・受けない |

- 影を**落とす**のは作品（額縁・作品面・彫刻）と展示台、**受ける**のは床・壁・展示台・彫刻。壁は影を落とさない（天井の外から光が差しているように見えるため）。
- 描画: Neutral トーンマッピング（明るい壁の白飛びを抑え、作品の色味を崩しにくい）、PCF ソフトシャドウ。影の範囲は部屋の大きさに合わせて自動で決める。
- 軽さ: 影は部屋が変わったときだけ描き直す。影の解像度は PC 2048px、指で操作する端末 1024px。低スペック向けの画質切替は TMS 64。

## アクセシビリティ
- すべての操作をキーボードでもできるようにする（Tab で移動、Enter / Space で決定、Esc で閉じる）。フォーカス枠は常に表示（`:focus-visible`）。
- 切替ボタンは `aria-pressed`、ツールパレットは `aria-label` を付けた `nav`。
- `prefers-reduced-motion` のときはアニメーションを止める（タイトル画面の背景の動きも止める）。
