# 提出版の体験定義：「1室を作り、作品を飾って、歩く」

確定: 2026-11-20（TMS 19行）。仕様の正本 [PRODUCT_SPEC.md](PRODUCT_SPEC.md) の「2026年11月提出版」を体験フローとして具体化したもの。
実装範囲と非対象の一覧は TMS 20行で別途文書化する。数値は初期値で、実装・実機確認で調整してよい。

## 一文で
**ブラウザを開いてすぐ、1つの展示室を歩いて6種類の作品を鑑賞でき、そのまま同じ部屋を自分で建て替え・飾り替えできる。**

## 誰のための体験か（優先順）
1. **審査員**：説明を読まず、URLを開いてから数分で価値が分かる必要がある（応募フォームに説明欄が1つしかないため → [CONTEST_REQUIREMENTS.md](CONTEST_REQUIREMENTS.md)）。
2. **作り手**：PCのChromeで部屋を作り、作品を飾る。
3. **スマホの来館者**：鑑賞だけできればよい（編集はPCを優先）。

## 体験の3段階
| 段階 | ユーザーがすること | 伝えたい価値 |
|---|---|---|
| ① 歩く（鑑賞） | サンプル美術館に入り、歩いて作品を見る。HTML作品のボタン・スライダーを**3D空間の中で**触る | 「美術館の中で作品が動く」 |
| ② 作る（建築） | 編集モードで床・壁をグリッドに置き、削除する | 「空間そのものを自分で作れる」 |
| ③ 飾る（展示） | 作品を壁・展示台に置き、位置を変える。鑑賞モードに戻って歩く | 「自分の世界が美術館になる」 |

**審査員の導線は ① → ② → ③ の順**とする。空の部屋から作らせると価値が伝わる前に離脱するため、まず完成したサンプルを見せ、同じ部屋を編集できるようにする。

## 画面とフロー
提出版の画面は **タイトル画面** と **3Dビュー（鑑賞モード / 編集モード）** の2つだけ。

```
タイトル画面
  ├─[サンプル美術館に入る]（主ボタン）──→ 3Dビュー・鑑賞モード（サンプル読み込み済み）
  └─[空の部屋から作る]（副ボタン）────→ 3Dビュー・編集モード（空の1室）

3Dビュー
  鑑賞モード ⇄ 編集モード（画面上のボタンで切替）
  ・前回の編集内容があれば、タイトル画面に [続きから] を出す（ブラウザ内保存）
  ・メニュー：JSON書き出し / JSON読み込み / サンプルに戻す / ヘルプ
```

### ① 鑑賞モード
- 一人称視点。**ドラッグで視点回転、WASD（矢印キー）で移動**。壁・展示物は通り抜けない。
- 作品に近づく / クリックすると、タイトル・解説パネルを表示。
- 動画・音楽はユーザー操作で再生/停止（自動再生しない）。
- GLB作品は拡大・回転して鑑賞できる。
- **HTML作品**（公式テンプレートのみ）：3D平面上のボタン・スライダーを直接操作できる。操作中はカメラ移動・回転と競合させない。
- HTML in Canvas非対応の環境では、同じHTML作品を通常DOMのパネルで開いて操作する（真っ白・停止にしない）。
- スマホ：タッチで視点回転と移動（簡易）。編集モードのボタンは出さないか、PCでの利用を促す表示にする。

### ② 編集モード：建築
- 部屋を上から斜めに見下ろす視点（鑑賞時の一人称とは切り替える）。
- **1室のみ**。グリッドの初期値は 1マス = 1m、最大 12×12マス、壁の高さ 3m。
- パーツは **床・壁** の2種類。展示台はGLB作品に付属、照明は固定、扉は作らない（→ [SUBMISSION_SCOPE.md](SUBMISSION_SCOPE.md)）。
- 配置前にプレビューを表示し、グリッドに吸着させる。配置済みのパーツは選択して削除できる。

### ③ 編集モード：展示
- 作品ライブラリ（同梱のサンプル作品）から選び、壁または床に置く。
- 置いた作品を選択して移動・削除し、タイトル・解説を表示する。
- 作品の種類は6種類：**画像・文章・動画・音楽・GLB・HTML作品（公式テンプレート）**。
- ユーザーによるファイルのアップロード・任意HTMLの投稿は対象外（同梱素材とJSONの入出力だけ）。

### 保存
- 編集のたびにブラウザ内へ自動保存し、リロードしても残る。
- JSONで書き出し・読み込みできる（動画などのバイナリはJSONに埋め込まず、同梱アセットのIDで参照する）。

## サンプル美術館（同梱）
- 1室に6種類の作品を **最低1点ずつ**、歩く順に並べる。入口から見える位置に **HTML作品** を置く（差別化を最初に見せる）。
- 素材はすべて自作か、利用許諾が明確なもの（TMS 68行）。合計サイズは公開上限100MBを大きく下回るよう軽量化する。

## 体験が成立したと言える条件（受入の目安）
1. タイトル画面から **1クリック** で、サンプル美術館を歩き始められる。
2. 何も読まずに、歩く・作品を見る・HTML作品を操作する、までできる（ヘルプは補助）。
3. 編集モードで壁を1枚追加・削除し、作品を1点移動して、鑑賞モードでその変化の中を歩ける。
4. リロードしても編集結果が残る。
5. HTML in Canvas非対応のブラウザでも、鑑賞とHTML作品の操作（DOMパネル）ができる。
