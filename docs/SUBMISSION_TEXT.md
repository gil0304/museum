## 作った理由や背景（案・約 700 字）

【きっかけ：例「自分の作ったものを、ただ並べるのではなく、ひとつの場所として見せたいと思ったこと」。ご自身の経験に置き換えてください】

作品を見せる場所は、多くの場合あらかじめ用意された枠です。ギャラリーサイトやSNSでは、どんな作品も同じ大きさのタイルに並びます。でも美術館では、壁の位置や部屋の広さ、作品同士の距離、歩く順番までが展示の一部です。そこで「部屋そのものから自分で作れる美術館」をブラウザの中に作りました。

解決したかったのは二つです。一つは、空間を作ることの難しさです。3Dソフトを使わなくても、マス目に床と壁を置くだけで部屋が建ち、すぐにその中を一人称で歩けるようにしました。もう一つは、Webで作った作品の展示です。HTMLで作った作品は、画面写真にすると「触れる」という一番大事なところが失われます。

こだわったのは、展示室の壁に掛けたHTML作品を、3Dの中でそのまま操作できることです。Chromeで使えるようになったばかりの HTML in Canvas を使い、本物のボタンやスライダーを壁の上に描き、歩きながら見る角度が変わってもクリックやドラッグが正しく届くようにしました。サンプルのHTML作品では、スライダーで展示室の明るさが変わります。対応していないブラウザでも、同じ作品をパネルで開いて触れるようにしています。

ほかにも、画像・文章・動画・音・3Dの6種類を同じ部屋に並べられること、編集が自動で保存されJSONで持ち運べること、サンプル作品の素材をすべて自分で作ったことなど、「開いてすぐ歩ける」体験を大切にしました。

## 短い紹介（X の投稿・作品ページの説明などに）
自分の世界を、美術館にする。床と壁を置いて展示室を建て、絵・文章・映像・音・3D、そして3Dの中で触れるHTML作品を飾って、その中を歩けるブラウザの美術館です。
