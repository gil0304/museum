## 作った理由や背景（約 750 字）

きっかけは、Chrome で「HTML in Canvas」が使えるようになったことです。これまで Web の 3D 空間に HTML を置こうとすると画像として貼るしかなく、ボタンもスライダーも押せませんでした。本物の HTML を 3D の中でそのまま触れるなら、Web で作った作品も、絵や映像と同じように「展示」できると考えました。

もう一つは、作品を見せるポートフォリオを、もっと気軽に作れるようにしたかったことです。ポートフォリオサイトでは、どんな作品も同じ大きさの四角に並びがちです。でも本当は、壁の色や光、作品同士の距離、歩く順番まで含めて「見せ方」だと思います。MUSEUM では、マス目に床と壁を置くだけで部屋が建ち、手持ちの画像・動画・音・3D モデル・文章を飾って、その中を一人称で歩けます。壁や床の色、光の暖かさ、ベンチや植物などの置き物で雰囲気も変えられます。インストールもログインもいらず、作った美術館はブラウザに自動で保存されます。

こだわったのは、HTML 作品を 3D の中でそのまま操作できることです。歩いて見る角度が変わってもクリックやドラッグが正しいボタンに届くよう、カメラの動きに合わせて毎フレーム位置を合わせています。サンプルの HTML 作品では、スライダーを動かすと展示室の明るさが変わり、HTML が 3D の世界を動かせることを体験できます。HTML in Canvas に対応していないブラウザでも、同じ作品をパネルで開いて触れるようにしました。サンプル美術館の画像・映像・音・3D モデルはこのアプリのために新しく作り、外部の素材は使っていません。
