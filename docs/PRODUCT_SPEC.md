# MUSEUM 企画・仕様 v1

## コンセプト
**自分の世界を、美術館にする。** 誰でもパーツで3D展示室を建築し、画像、文章、動画、音楽、3Dオブジェクト、操作可能なHTML作品を展示できる。来館者は3D空間を歩いて鑑賞できる。

## 差別化
- 完成済みテンプレートへの投稿だけでなく、床・壁・扉・展示台等を自分で構築する。
- HTML in Canvasを用いて、展示されたHTML作品のボタン・スライダー等を操作できることを核にする。
- 空間・照明・鑑賞導線も創作対象にする。

## 画面
トップ、展示一覧、美術館詳細、3D鑑賞、マイページ、作成、建築エディタ、展示エディタ、公開設定、作品ライブラリ、プロフィール、ログイン。

## 2026年11月提出版（TMS 17〜73行）
体験フローの詳細: [SUBMISSION_EXPERIENCE.md](SUBMISSION_EXPERIENCE.md) / 実装範囲・非対象: [SUBMISSION_SCOPE.md](SUBMISSION_SCOPE.md) / 応募要件: [CONTEST_REQUIREMENTS.md](CONTEST_REQUIREMENTS.md)
- 1室から始める。グリッド床・壁・照明・編集/鑑賞切替。
- 画像・文章・動画・音楽・GLB・HTML作品（公式テンプレート）を表示・操作。
- JSON入出力、ブラウザローカル保存、サンプル展示を同梱。
- 静的デモURLで第三者がサンプルを鑑賞できる。
- **ユーザーごとの公開美術館URL・ユーザーアップロード・本格認証は対象外。**
- 提出締切・要件は公式ソースで確認してから確定する。

## 正式MVP（12月以降）
- グリッド建築（目標3部屋）、作品管理、作品数上限、ユーザー認証、オンライン保存、共有URL、公開範囲設定。
- 作品は保存時にJSONメタデータ + ストレージファイルを分離。
- スマートフォン鑑賞・ブラウザ非対応時のフォールバック・安全なアップロード。

## 将来機能
複数階、自由建築、インタラクティブ作品エディタ、共同編集、イベント、コミュニティ、販売。

AI自動生成、フル3Dモデリング機能、来館者同時接続、任意の外部HTML/JSの直接実行。
