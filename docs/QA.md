# 通し確認の記録

## TMS 65：Chrome で建築から鑑賞まで（2026-11-27）
本番ビルド（`npm run release` → `vite preview`）を Google Chrome で、仕様の「体験が成立したと言える条件」（[SUBMISSION_EXPERIENCE.md](SUBMISSION_EXPERIENCE.md)）に沿って操作した。Claude in Chrome による自動確認（クリック・ドラッグは実際のマウス操作、長押しの移動キーはページにキーの押す・離すを送った）。**人間による実機確認は未実施**。

| 条件 | 操作 | 結果 |
|---|---|---|
| 1. タイトルから 1 クリックで歩き始める | 保存を消した状態でタイトル →「サンプル美術館に入る」 | ✅ 入口から奥の壁（HTML 作品）を向いて立つ。初回の案内が出る |
| 2. 何も読まずに、歩く・見る・HTML 作品を操作 | 案内を閉じずに：HTML 作品「拍手する」×2、W で前進、Q で左を向く、文章・動画をクリック | ✅ 拍手 2、文章の解説、動画の一時停止、音の再生・停止、3D 作品を近くで回して見る（6 種類すべて） |
| 3. 壁を 1 枚追加・削除、作品を 1 点移動し、鑑賞でその中を歩く | 編集：壁を 2 枚置いて 1 枚削除、3D 作品を M で移動 → 鑑賞で歩く | ✅（修正後）。**不具合を発見**：編集の URL から入って初めて鑑賞にすると、立ち位置が原点のままで、置いた壁に体が重なり、「埋まった位置からは出られる」決まりで壁を通り抜けた。初めて鑑賞にしたときは入口から始めるよう修正し、入口から歩くと壁の手前（0.35m）で止まることを確認 |
| 4. 読み込み直しても編集が残る | ページを読み込み直し → タイトルの「続きから」 | ✅ 置いた壁・動かした作品が残る |
| 5. 非対応ブラウザでも鑑賞と HTML 作品の操作 | Chrome で `?fallback=1`（TMS 53・54 で確認） | ✅（本物の Safari・Firefox は TMS 66、未実施） |

その他：コンソールのエラーなし。ブラウザ拡張との接続が 2 回切れたため、途中から新しいタブで続けた（アプリの問題ではない）。
