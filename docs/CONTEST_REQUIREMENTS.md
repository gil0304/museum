## 応募資格
- 日本国内在住。年齢制限なし（未成年は保護者の同意が必要）。
- 応募無料。Freeプランのままで応募可。個人・法人可。応募点数の制限なし（1作品ごとにフォーム送信）。
- 応募者本人が制作した作品であること。AIと一緒に作った作品も可。
- 公開者（デプロイナウのアカウント）と応募者が同一であること。

## 提出物・応募方法
1. **ロリポップ！デプロイナウで作品を公開**する（他所で公開中の作品も、デプロイナウで公開し直せば可）。
2. 特設サイトの**応募フォーム**に、公開URLと必要事項を入力して送信。**送信をもって応募完了**。
   - 作品についての記述項目は次の1つだけ（2026-11-18 ユーザーがフォームで確認）:
     > 応募作品について、作った理由や背景を教えてください
     > ※作ろうと思ったきっかけ、解決したかったこと、こだわった点など、自由にお書きください。
   - スクリーンショットや技術説明の提出欄は無い。→ **作品ページ自体（トップ・README相当の導線）で体験とこだわりが伝わる必要がある**。
   - 文案は「きっかけ / 解決したかったこと / こだわった点（自分で建築する美術館・HTML in Canvasで操作できる展示）」の3点で構成する。
   - X（旧Twitter）への投稿だけでは応募にならない。
- ジャンル・テーマ不問。応募期間前に公開した作品も可。

## 無効・取消になる条件
- 審査終了までに作品が非公開・削除された場合
- フォームの内容が作品と一致しない場合 / 公開者と応募者が異なる場合
- 応募条件・法令・注意事項・公序良俗に違反、または主催者が不適当と判断した場合
- 受賞後も一定期間は公開を維持する必要がある

## 権利・素材
- 作品の権利は応募者に帰属。主催者は作品名・スクショ・URL・説明を広報に無償利用できる。
- 第三者の権利（AI生成要素を含む）を侵害しないこと。**サンプル展示の画像・音楽・動画・GLBは自作か利用許諾が明確な素材に限る**。

## 審査
- 詳細基準は非公開。「完成度や規模だけでなく、どのようなアイデアをどのように形にしたか」を評価（プレスリリース）。
- グランプリ100万円 / 準グランプリ30万円 / 審査員特別賞10万円 / 月間賞1万円。
- 審査員: catnose、けんすう、シモダテツヤ、宮本 佳林（特別審査員）。

## デプロイナウの技術条件（本プロジェクトへの影響）
- 静的サイト（HTML/CSS/JS）対応。Viteの明示的な記載はないが、`npm run build` の `dist/` を静的サイトとして公開する方針で整合する（実際のデプロイ手順は該当タスクで実機確認）。
- 公開手段: CLI（`npm i -g lolipop` → `lolipop deploy`）、GitHub連携（push毎デプロイ・PRプレビュー）、ビルド済みフォルダのドラッグ&ドロップ。
- Freeプラン: **デプロイサイズ上限100MB**、CDN帯域100GB/月、商用可、カスタムドメイン可。1ファイル上限は記載なし。
  - → サンプルの動画・音楽・GLBは軽量化し、合計100MBを大きく下回るよう管理する。
