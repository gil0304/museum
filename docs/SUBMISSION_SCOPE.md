### 19行で保留にしたパーツの扱い
| パーツ | 提出版での扱い | 理由 |
|---|---|---|
| 床・壁 | **建築パーツとして配置・削除できる** | TMS 40–42 |
| 展示台 | **GLB作品に付属する固定の台**として表示する。単独の建築パーツにはしない | TMS 51が「GLBを展示台に表示」。建築パーツを増やす行は無い |
| 照明 | **部屋全体の基本照明だけ**（固定）。ユーザーが照明を置く機能は作らない | TMS 35は基本照明の調整のみ |
| 扉 | **作らない** | 1室なので部屋同士をつなぐ必要が無い |
| 天井 | 初期展示室に固定で表示する。編集の対象外。データには持たず、床・壁の範囲を覆う板を壁の上端に自動で張る（下向きの片面なので編集時の斜め上からの視点を遮らない） | TMS 34 で実装 |

### 作品の扱い
- 種類は6種類：画像・文章・動画・音楽・GLB・HTML作品。
- 作品の素材は**アプリに同梱したものだけ**。JSONは同梱素材のIDで参照する（動画などのバイナリをJSONに埋め込まない）。
- HTML作品は**公式テンプレートだけ**。テンプレートのHTML/JSは同梱のコードで、利用者が書き換えたコードは実行しない。
- 文章作品・タイトル・解説のテキストはJSONで持つ（テキストとして表示し、HTMLとしては解釈しない）。

### 対応環境
| 環境 | 提出版での扱い |
|---|---|
| PCのChrome（HTML in Canvasが使える版） | **主対象**。建築・展示・鑑賞のすべて |
| PCの他ブラウザ / HTML in Canvas非対応のChrome | 鑑賞と建築は使える。HTML作品は通常DOMパネルで操作 |
| スマホ | 鑑賞だけ（簡易タッチ操作）。編集の作り込みはしない |

## 2. 今回は作らない機能

### 12月以降の正式MVPで扱う
- ユーザー登録・ログイン・本格的な認証
- オンライン保存、ユーザーごとの公開美術館URL、共有URL、公開範囲の設定
- ユーザーによる画像・動画・音声・GLBのアップロード、作品数の上限管理
- 複数の部屋（目標3部屋）、扉で部屋をつなぐ
- 展示一覧・美術館詳細・マイページ・プロフィール・作品ライブラリ・公開設定の各画面
- スマホでの編集、ブラウザ非対応時のフォールバックの作り込み

### 将来の検討
- 複数階、グリッドにとらわれない自由建築
- インタラクティブ作品エディタ（利用者がHTML作品を作る機能）
- 共同編集、イベント、コミュニティ、販売

### 今回の非目標（作らない）
- AIによる自動生成
- 本格的な3Dモデリング機能
- 来館者の同時接続（他の来館者が見える等）
- **任意の外部HTML/JSの直接実行**
- 照明・展示台・扉の自由配置、壁紙やテクスチャの細かい編集、元に戻す/やり直し（TMSに行が無いため）

## 3. 締切に間に合わない場合の考え方（提案）
TMSの計画（順番・優先度）は変更しない。進みが遅れたときの判断材料として、**応募の価値を支えるもの**を明記しておく。

1. **最後まで守る**：公開URLで開ける（60–61, 69）／サンプル美術館を歩ける（33–38, 58–59）／3D空間内でHTML作品を操作できる＋非対応時の代替（22–28, 53–54）／素材の権利（68）／フォーム送信（72）
2. **価値の柱**：床・壁の建築（39–43）、6種類の作品表示（45–52）、ブラウザ内保存（57）
3. **11/30以降でも改善できる**：JSON入出力（55–56）、画質切替（64）、スクショ・デモ（71）。月間賞の選考は11/30時点の内容だが、本選の締切12/8までは修正が反映される。

## 2026-11-27 の変更（ユーザーの指示）
- **自分の作品のアップロードを提出版に入れた**：画像（png・jpeg・webp・gif、15MB まで）・動画（mp4・webm、80MB）・音（mp3 など、30MB）・3D（外部ファイルを参照しない .glb、50MB）・文章（.txt、100KB）。このブラウザの IndexedDB にだけ保存し、サーバーには送らない。HTML のアップロードは安全のため対象外のまま（公式テンプレートだけ）。
- **自分の美術館を複数持てる**：「美術館をつくる」で空の部屋から作り、名前を付けられる（編集中に上部バーの名前を押す）。サンプルは見るだけで、編集すると複製して自分の美術館にする。メニューから削除できる。
- 関連する TMS 行：55〜57（保存）・62（ヘルプ）・70（紹介）。予定の行は変えていない。
- **雰囲気（色と光）を編集できる**：編集の道具「雰囲気」（C）で、プリセット（ギャラリー・白・木・夕暮れ・夜）、壁の色・床の色、明るさ、光の色（青白い〜暖かい）。選んだ壁・床だけの色も変えられる（色見本）。美術館データの `style` に保存し、JSON にも入る。
- **置き物を追加できる**：編集の道具「もの」（O）で、内蔵の置き物（ベンチ・植物・柱・低い台・ランプ・ラグ。three.js の形で作り、外部の素材なし）と、自分の 3D モデル（.glb、台座なし、長い辺を 0.2〜4m に収める）。R で 45° ずつ回す。歩くときにぶつかる（ラグは上を歩ける）。鑑賞ではクリックしても解説を出さない。
- 当初「照明は固定」「展示台は GLB 作品に付属」としていた範囲を広げた（照明は雰囲気として全体の明るさ・色だけ。光源を置く機能は無い）。
